01 · 规则

完整 HUNL 状态模型

52 张牌、四个下注轮次、盲注、终局收益、牌型评估，以及弃牌到全押的动作抽象。

02 · 求解

CFR 子博弈求解

遗憾更新、平均策略、到达概率、最佳响应、期望收益与可利用度相关工具。

03 · 递归

手牌信念传播

从公共状态展开子博弈，按行动更新双方私牌信念，并在后续状态继续求解。

04 · 学习

反事实价值网络

使用 PyTorch 对截断叶节点估值，支持价值与策略学习实验。

05 · 数据

自博弈与经验回放

多进程样本生成、模型同步、回放缓冲、训练批次和验证流程。

06 · 原生计算

C++ 蒙特卡洛组件

原生模拟器、Python 牌型工具与绑定基础设施，补充 Python 算法层。

玩法模型与算法流程

引擎覆盖翻牌前、翻牌、转牌和河牌。公共状态记录公共牌、累计下注、当前行动者、可行行动与加注次数。

1. 构建公共状态

2. CFR 遍历子博弈

3. 自博弈训练

反事实价值与策略样本经回放系统进入 PyTorch 模型。
