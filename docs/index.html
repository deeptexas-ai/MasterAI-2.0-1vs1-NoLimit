What the public source actually contains

Every capability below maps to a visible module. Unsupported claims about OCR, automatic online play, one-click executables or guaranteed performance are intentionally excluded.

01 · GAME

HUNL rules and state tree

Cards, streets, blinds, terminal utilities, hand evaluation and an action abstraction from fold to all-in.

02 · SOLVING

CFR subgame solver

Regret updates, average strategies, reach probabilities, best response, expected value and exploitability utilities.

03 · RECURSION

Belief-aware recursive solving

Build subgames from public states, propagate private-hand beliefs and continue solving after sampled actions.

04 · LEARNING

Counterfactual value networks

PyTorch models estimate leaf values and support configurable value and policy learning experiments.

05 · DATA

Self-play and replay

Multiprocess generation, model synchronization, replay buffers, training batches and validation workflows.

06 · NATIVE

C++ Monte Carlo layer

A native simulator and Python-binding foundation complement the Python game and learning modules.

From public state to learned strategy

The repository separates rules, solving and learning so each stage can be tested or extended independently.

1. Model the game

The HUNL engine creates legal public states across preflop, flop, turn and river.

2. Solve subgames

CFR traversals update regret and average policy; value networks can estimate truncated leaves.

3. Train from self-play

Generated counterfactual-value and policy samples flow through replay into PyTorch models.
